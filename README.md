# Atlas Drift (أطلس دريفت)

لعبة سباق بالانزياح (Touge Drift) عبر جبال الأطلس — مبنية بالكامل بـ **GDScript** على
**Godot 4.7**. كل شيء مُولَّد برمجياً وقت التشغيل: الحلبة الجبلية، الشاحبات، الأصوات،
الأزرار، والأيقونات — لا توجد ملفات أصول ثنائية إطلاقاً (عدا خط Tajawal العربي).

## اللعب
- حلبة جبلية مغلقة ~2.3 كم، ارتفاع 3→62 م، منعطفان حادان (hairpins) وانحدارات
- فيزياء هجينة: أساس arcade ثابت + انزلاق خفيف عند تجاوز حد التماسك في السرعات
  العالية + زر انزياح يدوي + قوة ضغط هوائي (downforce) تتزايد مع السرعة + فرامل ABS
- لفات مع 3 نقاط تفتيش، أفضل لفة محفوظة على الجهاز، كشف الاتجاه الخاطئ، إحياء تلقائي
- نقاط انزياح تُحسب من زاوية الانزلاق × السرعة

## التحكم (اللمس)
| الزر | الوظيفة |
|------|---------|
| ◀ / ▶ (يسار الشاشة) | التوجيه |
| بنزين (يمين) | تسريع |
| فرامل | فرملة/رجوع |
| انزياح | فرملة يد للانجراف |

لوحة المفاتيح على الحاسوب: أسهم/WASD + مسافة (انزياح) + R (إحياء) + Esc (قائمة).

## البناء
يُبنى الـ APK تلقائياً عبر GitHub Actions عند كل دفع إلى `main`
(Godot 4.7.2 headless + قوالب التصدير + zipalign/apksigner بمفتاح إصدار ثابت).

بناء محلي:
```bash
godot --headless --path . --import
godot --headless --path . --export-release "Android" build/AtlasDrift.apk
```

اختبار دخاني بدون شاشة (يقود السيارة فعلياً ويتحقق من الحركة):
```bash
godot --headless --path . -- --smoke
```

## البنية
```
scripts/
  main.gd           نقطة الدخول: مدخلات، خطوط، قائمة/عالم، اختبار دخاني
  menu.gd           القائمة الرئيسية (عربية RTL)
  game.gd           منسّق السباق: لفات/tفتيش/عدّاد/انزياح/إحياء
  track_gen.gd      توليد الحلبة: تنعيم لابلاسي + مصرف تحليلي + حواجز بمصادمات
  car.gd            فيزياء هجينة على CharacterBody3D
  hud.gd            عدادات عربية + سطر تصحيح
  touch_controls.gd أزرار لمس متعددة مولّدة
  audio_synth.gd    تخليق صوت المحرك/الانزياح/الصفارات (WAV وقت التشغيل)
  ui_kit.gd         أدوات رسم واجهة
```
